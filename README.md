# Punter Scoreboard

An unofficial Ricky Ponting fan site. Not affiliated with Ricky Ponting, Cricket Australia, the ICC, the BCCI, the IPL or any team.

Next.js 15 (App Router), TypeScript, Tailwind CSS v4, shadcn/ui, Motion, Recharts. Deployed on Vercel.

```powershell
npm install
Copy-Item .env.example .env.local   # then fill in values
npm run dev
```

- `PLAN.md` — phases and "done when" checks
- `PROGRESS.md` — running log and the list of unverified numbers
- `CLAUDE.md` — project rules (all stats in `src/data/*.json`, every number sourced)
